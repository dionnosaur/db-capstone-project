# Meta Data Engineering Specialization Capstone Project

**Author:** Dionne Barajas  
**Project Type:** Database Design & Implementation Capstone  


## Project Overview  
This project simulates a restaurant reservation system to demonstrate database design, querying, and data analysis skills.  
It was developed as part of a database engineering certification to show an understanding of how data can be structured, stored, and retrieved efficiently.

## Key Components  
- **Data Model:** Entity-relationship diagram (`LittleLemonDataModel.png`)  
- **Database Schema:** SQL file defining tables and relationships (`LittleLemonDB.sql`)  
- **Data Population:** Scripts to insert sample records (`Populating Database Tables.sql`)  
- **Stored Procedures:** Functions to add, cancel, and manage bookings (`AddBookingProcedure.sql`, `CancelBookingProcedure.sql`)  
- **Client Notebook:** Jupyter notebook for running SQL queries and analyzing data (`Little Lemon Database Client.ipynb`)  
- **Visualization:** Tableau workbook for summarizing restaurant data (`LittleLemonTableauWB.twb`)  

## Technologies / Tools  
- MySQL Workbench  
- Jupyter Notebook  
- Tableau  

## How to Run  
1. Clone this repository.  
2. Open `LittleLemonDB.sql` in MySQL Workbench to create the schema.  
3. Run `Populating Database Tables.sql` to load sample data.  
4. Execute stored procedures to test booking functions.  
5. Use the Jupyter notebook to connect to the database and run queries.  
6. Open the Tableau workbook to explore simple data visualizations.

## Skills Demonstrated  
- Relational database design  
- ER diagram modeling  
- SQL queries (joins, subqueries, and views)  
- Stored procedures and parameterized queries  
- Jupyter-based database client creation  
- Basic data visualization with Tableau
